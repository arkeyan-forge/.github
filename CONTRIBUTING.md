# Contributing to Arkeyan

Thanks for wanting to help! Bugs, ideas and questions for every game go to the
[launcher's issues](https://github.com/mflr0/Arkeyan-Launcher/issues/new/choose), so that everything is in one place. Before a pull request, read the
launcher's [CONTRIBUTING.md](https://github.com/mflr0/Arkeyan-Launcher/blob/main/CONTRIBUTING.md): the same rules apply here (an issue first for a feature,
signed-off commits, one subject per pull request, nothing from a game, no code copied from another project).
